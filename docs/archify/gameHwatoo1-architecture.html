git.gameHwatoo1 architecture

Vite + TypeScript + Three.js Hwatu game. Runtime entrypoint: src/main.ts.

Runtime layers

  • Bootstrap/UI: src/main.ts, index.html
  • Domain: src/game/
  • Rendering: src/three/
  • Assets: src/utils/AssetManager.ts and public/cards/

Game model

  • 48 cards / 12 families / 4 cards per family
  • Opening deal: 10 + 10 + 8 + 20
  • Match types: none, single, choice, triple
  • Turn: hand play → deck draw → Go/Stop check

Primary flow

main.ts creates Game. Game owns GameState, evaluates matches through rules.ts, and coordinates Three.js objects. Domain events return to main.ts through EventBus for status, capture, choices, Go/Stop and result overlays.
