# 화투 게임 진행 정리 및 우선순위

작성일: 2026-09-08

## 오늘 확인한 문제와 결정

### 카드와 룰

- 화투는 48장, 12개월 × 4장 구조다.
- 같은 달 4장이 한 조이며, 매칭 기준은 카드 종류가 아니라 월이다.
- 카드 ID의 앞 두 자리(`01`~`12`)를 조 판정의 기준으로 사용한다.
- 손패를 한 장 내고 바닥의 같은 달 카드와 매칭한다.
- 이후 더미에서 한 장을 뒤집어 공개하고 다시 매칭한다.
- 같은 달 카드가 2장 있으면 실제 카드 이미지와 함께 하나를 선택해야 한다.
- 매칭 카드가 보이지 않는 문제는 획득패 배치가 겹쳤기 때문이며, 획득패를 별도 트레이에 배치한다.

### 이미지 매핑

- 원본 SVG는 12열 × 4행이 아니라, 각 월 4장씩 묶인 3블록 × 4행 배열이다.
- 기존 절단 좌표가 잘못되어 메타데이터의 월과 화면 그림이 어긋났다.
- `AssetManager`에서 실제 SVG 배열에 맞춰 1월~12월을 매핑했다.
- 선택창은 공통 placeholder가 아니라 각 카드의 실제 썸네일을 표시한다.

### 화면 배치

- 기본 카드 크기는 화면 비율에 따라 전체적으로 조절한다.
- 손패·바닥패는 기본 크기를 사용한다.
- 선택·매칭 효과에서만 잠시 확대한다.
- 상대 손패, 바닥패, 더미, 내 손패, 획득패는 서로 다른 영역이어야 한다.
- 게임 중 하단의 새 게임 버튼은 손패를 가리므로 숨기고, 종료 결과창의 다시 시작으로 통합한다.

### 점수와 종료

- 광·열끗·띠·피의 기본 점수를 계산한다.
- 비광 포함 3광, 고도리, 홍단·청단·초단, 쌍피를 고려한다.
- 점수 획득 시 `광 3장 = 3점`처럼 근거를 표시한다.
- 기준 점수에 도달하면 GO/STOP 선택을 표시한다.
- CPU STOP과 게임 종료는 큰 결과 오버레이로 표시한다.

## 현재 완료된 항목

- 기본 48장 덱과 10장/10장/8장 배분
- 손패 제출과 바닥 매칭
- 더미 카드 공개 및 매칭
- 2장 후보 선택
- 카드 이미지 스프라이트 매핑 수정
- 반응형 카메라·카드 배치
- 손패 간격 조정 및 CPU/바닥패 겹침 수정
- 획득패 2장 이상 표시용 트레이
- 획득 장수와 점수 근거 안내
- GO/STOP 기본 흐름
- CPU STOP 결과 오버레이
- 카드 중복·누락·월별 4장 상태 검증
- 시드 주입 가능한 셔플 함수
- 빌드 및 Playwright 화면 캡처 검증

## 앞으로의 우선순위

### P0: 실제 게임 흐름 안정화

1. 게임 중 새 게임 버튼 숨김 및 종료 후 다시 시작으로 통합
2. 손패 제출 → 매칭 → 더미 공개 → 매칭 → 획득의 상태 전환 테스트
3. 매칭 결과가 항상 2장 이상 올바르게 획득되는지 검증
4. 뻑·쪽·따닥·폭탄 판정

### P1: 정확한 점수와 종료 규칙

1. 홍단·청단·초단·고도리 상세 점수
2. 피박·광박·멍따
3. GO 횟수와 배수
4. 결과창 점수 계산 근거와 승패 표시

### P2: 테스트

1. 48장 중복·누락·월별 4장 단위 테스트
2. 0/1/2/3장 매칭 테스트
3. 더미 공개와 후보 선택 테스트
4. GO/STOP 상태 테스트
5. 휴대폰·태블릿·데스크톱 Playwright 테스트
6. 시드 기반 리플레이 테스트

### P3: 확장

- CPU 난이도
- 흔들기
- PvP 준비 구조
- 저장·복구·리플레이
- 사운드·진동

## 다음 작업 원칙

- 게임 상태와 렌더링 애니메이션을 분리한다.
- 상태 변경 후 48장 불변식을 검증한다.
- 화면에 보이는 카드와 실제 카드 상태가 다르면 이미지·영역·상태 순서로 점검한다.
- 새 룰을 추가할 때 먼저 룰 함수를 검증한 뒤 애니메이션과 UI를 연결한다.
