# 2026-09-08 대화 정리 및 다음 작업

## 이번 대화에서 확정한 방향

### 화면·반응형 배치

- 지원 화면 비율은 16:9, 9:16, 4:3, 3:4를 기준으로 한다.
- 전체 카드 그룹을 단순 축소하지 않고 화면 비율별 게임판 영역을 다시 계산한다.
- 상대 손패와 내 손패는 모든 카드를 완전히 펼치지 않고 약 2/3 노출을 기본으로 한다.
- 선택한 카드는 잠시 확대하고, 매칭 후보는 별도 강조한다.
- 손패·바닥패는 기본 크기, 더미는 기본 크기의 약 78%, 획득패는 약 58%를 기준으로 한다.
- 획득패는 손패·바닥패와 다른 트레이에 배치하며, 후반에는 카테고리별 요약/상세 패널을 검토한다.
- 시작 버튼은 게임판 하단에 상시 배치하지 않고 시작 화면 중앙 또는 결과 모달의 다시 시작 버튼으로 분리한다.
- HTML UI 오버레이가 차지하는 상·하단 안전 영역을 먼저 확보한 뒤 Three.js 카드 위치를 계산한다.
- 화면 회전·모바일 safe area·`100dvh`·터치 클릭 영역·겹친 카드의 선택 우선순위를 포함해 검증한다.
- Orthographic 카메라 도입은 현재 Perspective 카메라의 비율별 크기 변화 문제를 줄이는 후보로 남긴다.

### 기본 룰·점수

- 화투는 48장, 12개월, 월별 4장 구조를 유지한다.
- 초기 배분은 플레이어 10장, CPU 10장, 바닥 8장, 더미 20장이다.
- 월 판정은 카드 표시 텍스트가 아니라 카드 ID의 월 가족을 기준으로 한다.
- 기본 점수는 광·열끗·띠·피·고도리·홍단·청단·초단을 설명 가능한 항목으로 계산한다.
- 쌍피는 피 2장으로 계산한다.
- 점수는 숫자만 표시하지 않고 점수 발생 항목과 기여 카드를 설명한다.
- 목표 점수, 고 계산 방식, 박, 흔들기, 폭탄 등은 지역·모임 룰 차이가 있으므로 `RuleProfile` 옵션으로 분리한다.

### 특수 이벤트

- 뻑·첫뻑·쓸·따닥·쪽·설사는 점수 함수에 직접 더하지 않고 턴 이벤트로 처리한다.
- 따닥은 바닥 같은 월 2장에 손패와 더미까지 같은 월이 나와 4장을 획득하는 흐름으로 별도 구현한다.
- 쪽은 손패를 내기 전 같은 월 바닥패가 0장이고 손패와 더미 카드가 같은 월인 경우 두 장을 함께 획득한다.
- 쪽 피 회수량은 `RuleOptions.jjokPiReward`의 0/1/2장으로 설정하며 기본값은 0장이다. 상대가 가진 피만 물리적 카드 수 기준으로 회수한다.
- 설사는 손패에서 짝을 맞춘 뒤 더미에서 같은 월이 나오는 조건으로 판정한다.
- 설사 발생 시 현재 구현은 획득을 취소하고 해당 패를 바닥에 남긴다.
- 설사 피 회수량은 0/1/2장 옵션으로 분리했다.
- 지역에 따라 첫뻑·첫따닥·쓸·따닥·쪽·설사에서 피를 회수할 수 있으므로 보상 여부와 장수를 각각 설정한다.
- 9월 국진처럼 열끗과 쌍피 중 역할을 선택하는 카드는 대체 역할 모델이 필요하다.

## 남은 작업 우선순위

### P0: 기본 플레이 가능 상태

1. 시작 화면 → 카드 배분 → 손패 선택 → 바닥/더미 매칭 → 턴 전환 → GO/STOP → 라운드 종료의 기본 흐름을 실제 화면에서 검증한다.
2. 카드 놓기·뒤집기·획득·쪽·설사·GO/STOP에 기본 효과음과 상태 안내를 연결한다.
3. 사용자 제스처 이후 BGM 재생, 음소거·볼륨 조절, 오디오 미지원/재생 실패 fallback을 추가한다.
4. 완료: `?seed=<값>` 기반 결정적 배분과 테스트용 RNG 주입으로 쪽·따닥·설사·후보 선택 재현 기반을 마련한다.
5. 완료: `validateCardZoneInvariants`로 손패·바닥·더미·획득패 합계 48장, 고유 ID, 월별 4장, 카드 메타데이터를 검증한다.
6. 390×844와 데스크톱 1280×800에서 화면 잘림·입력 잠김·콘솔 오류 없는지 고정 검증한다.

### P1: 기본 UX 다듬기

1. 완료: 게임 시작 화면에 목표 점수와 쪽·설사 피 회수량 최소 룰 옵션을 배치한다.
2. 완료: 점수·룰 바텀시트를 현재 `RuleOptions`와 연결한다.
3. 진행 중: 손패 선택 표현과 매칭 후보 바닥패 강조를 연결했다. 획득 결과 전체 시각 효과와 상태 문구 통일은 사용자 화면 확인 후 보완한다.
4. 16:9·9:16 중심으로 카드 좌표와 안전 영역을 조정하고, 이후 4:3·3:4를 추가한다.
5. BGM·효과음 에셋을 `public/audio/`에 정리하고 라이선스와 출처를 기록한다.

### P2: 고급 룰·확장 품질

1. `RuleProfile`을 기본 룰/맞고/사용자 설정으로 확장한다.
2. 고 계산, 피박·광박·멍박·고박, 흔들기·폭탄·나가리 옵션을 추가한다.
3. 국진 등 대체 역할 카드와 카드별 `piValue` 모델을 추가한다.
4. seed·action log 기반 리플레이 테스트와 이벤트 수명주기 정리를 진행한다.
5. Combos CLI 업로드·배포 가능성을 확인하고, 필요하면 생성 오디오를 게임 에셋으로 교체한다.
