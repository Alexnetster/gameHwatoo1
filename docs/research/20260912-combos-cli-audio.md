# 2026-09-12 Combos CLI·오디오 검토 기록

## 대화 요약

- `docs/rearch/cosmocli.md`를 기준으로 Combos는 게임 생성, 에셋 생성, 배포와 공유를 묶은 플랫폼으로 검토했다.
- 우리 게임은 현재 Vite + Three.js 기반이며, 저장소에는 Combos CLI 연동 코드나 설정이 없다.
- 먼저 현재 맞고 게임의 핵심 턴 흐름을 완성하고, Combos는 작은 PoC로 실제 지원 범위를 확인하기로 했다.
- Combos 공식 페이지 기준으로 BGM과 클릭·매칭·승리·패배 효과음은 Audio 에셋으로 생성·업로드·개별 교체할 수 있다.
- 다만 Combos 웹 에디터의 Audio 기능과 CLI의 실제 명령어·프로젝트 업로드 방식은 구분해야 하며, CLI 지원 여부는 직접 검증해야 한다.

## 오디오 PoC 계획

1. Combos에서 BGM 1개와 효과음 3개를 생성한다.
2. 생성 파일의 다운로드, 포맷, 라이선스와 상업적 사용 조건을 확인한다.
3. `public/audio/`에 복사하고 카드 놓기·획득·점수 이벤트에 연결한다.
4. 게임 시작 버튼 이후 BGM을 재생하고 음소거·볼륨 설정을 제공한다.
5. Playwright로 재생, 음소거, 재시작과 모바일 동작을 검증한다.

## 권장 오디오 목록

- `bgm-main`: 가사 없는 전통 악기풍 반복 BGM
- `card-place`: 카드 놓기
- `card-capture`: 패 획득
- `score-achieved`: 점수 발생
- 이후 `go`, `stop`, `game-win`, `game-lose`를 추가한다.

브라우저 자동재생 제한 때문에 오디오는 사용자의 `새 게임 시작` 클릭 이후 초기화해야 한다. 외부 음원을 업로드할 경우 사용 권한이 확인된 파일만 사용한다.
